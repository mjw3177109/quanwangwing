# 资源与许可证边界

- FFDec 的许可证文件位于 FFDec/license.txt；该工具及其库的许可证条款应按仓库内许可证文件执行。
- 拳皇 Wing SWF 中的角色、美术、声音、音乐、商标和游戏内容可能涉及第三方权利。仓库中存在文件并不自动证明其可再分发。
- 分析工具默认把导出资源写入本地 build/swf-analysis/ 或 GitHub Actions artifact，不自动提交这些导出文件。
- 只有在确认拥有相应再分发权或获得授权后，才将原版提取资源加入公开发布包。
- HTML5 引擎代码与由 SWF 提取的原版内容分开管理，避免误把工具许可证当作游戏资产许可证。
