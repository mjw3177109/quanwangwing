# M1: 动态挂载标识符跨脚本引用证据

对已通过哈希校验的 FFDec AS2 导出，提取 `attachMovie` 动态首参数中的标识符 SHA-256，再对全部脚本进行词法遮蔽后的同哈希匹配。报告提供原始脚本相对路径、行号、词法类别、同文件调用前/后及跨文件出现次数；例子有上限，汇总计数不截断。报告不写入标识符明文、未知字符串、原版 AS2 源码、美术或音频。

入口：`tools/build_attach_identifier_references.py`；CI 在 AS2 导出、`attach-argument-provenance.json` 通过后运行，上传 `attach-identifier-references.json` 元数据。校验 SWF 来源 SHA、每个 AS2 文件长度和 SHA-256、候选位置及计数，异常立即失败。

**证据边界**：跨文件相同标识符不等于同一个变量；函数参数、局部变量遮蔽、动态属性、执行分支与赋值顺序均未解析。输出仅帮助优先定位第 17 帧两处动态参数的潜在定义和使用点，不得据此推断最终角色资源名称、碰撞箱或招式行为。
