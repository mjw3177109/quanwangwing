# HTML5 重构计划与验收标准

## 原则

- 原版 SWF 是事实来源；不凭印象重写动作、帧数、角色属性或 UI。
- 先解析，再建模；每项推断记录证据（脚本名、字符 ID、帧号、标签索引或导出文件）。
- 游戏逻辑以固定时间步推进，渲染帧率与战斗帧率分离。
- 每次提交只推进可验证的增量，不把占位动画当作完成内容。

- 舞台尺寸与帧率
- 动画帧数、顺序、锚点和播放速度
- 输入窗口、指令识别、优先级和缓冲
- 攻击判定、受击判定、推挤判定与伤害/硬直

- UI 布局、文本、状态与转场
- 对战流程、胜负条件、计时与平局规则

只有全部关键用例通过原版对照，才能将版本标记为 1:1 验收通过。
